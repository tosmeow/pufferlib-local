Examples
========

The ``examples`` directory contains compatibility examples for other environment
interfaces and a small Puffer training example.

Files
-----

* ``examples/gym_env.py``: Gym-style environment wrapper example
* ``examples/gymnasium_env.py``: Gymnasium-style environment wrapper example
* ``examples/pettingzoo_env.py``: PettingZoo-style environment wrapper example
* ``examples/puffer_env.py``: native Puffer environment example
* ``examples/pufferl.py``: compact training-loop example
* ``examples/render.py``: render helper/example
* ``examples/structured_env.py``: structured observation/action example
* ``examples/vectorization.py``: vectorization example
